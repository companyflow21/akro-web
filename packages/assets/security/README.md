# security

Bildwelt **AKRO Sicherheit** (`akro-sicherheit.de`). Farbwelt Blau/Cyan.

Motive dieser Bildwelt werden nicht von anderen Marken mitbenutzt
(`docs/DECISIONS.md` Punkt 23).

## Bedarf je V1-Leistung

| Leistung | Motividee |
| --- | --- |
| Objekt- und Werkschutz | bewachtes Werksgelände, Zutrittspunkt |
| Revier- und Kontrolldienst | Kontrollgang, Fahrzeug im Einsatz |
| Veranstaltungssicherheit | Einlass, Absperrung, Veranstaltungsgelände |
| Baustellenbewachung | gesicherte Baustelle außerhalb der Arbeitszeit |
| Empfangs- und Pfortendienst | besetzter Empfang, Besucherannahme |
| Personenschutz | diskrete Begleitung, zurückhaltend dargestellt |
| KRITIS-Schutz | technische Anlage mit erhöhter Zutrittssicherung |

Zusätzlich: ein Hero-Motiv und ein OG-Bild.

## Bestand

**Leer.** Alle Leistungsbilder des Altbestands sind zerstört.

## Regeln

- Keine Uniform-, Fahrzeug- oder Ausstattungsdarstellung, die nicht der
  Realität entspricht.
- Keine Waffen, keine Bodyguard- oder Militäroptik.
- Bild-KI ist für fachliche Motive zulässig, **nicht** für echte
  Mitarbeitende, echte Objekte oder echte Einsätze.
- Abgebildete Personen brauchen eine Einverständniserklärung.
