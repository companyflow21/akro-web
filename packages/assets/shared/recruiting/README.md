# shared/recruiting

Bildmaterial für Karriere- und Bewerberbereiche über alle Marken hinweg.

## Bedarf

Einstieg und Einarbeitung, Ausrüstung, Schulung, Team — Motive, die auf
Bewerbende einladend wirken.

## Bestand

**Leer.**

## Gestaltungshinweis

Bewerberbereiche dürfen wärmer und heller wirken als die sachlicheren
Kundenbereiche.

## Regel

Echte Mitarbeitende nur mit schriftlicher Einverständniserklärung. Für
allgemeine Stimmungsmotive ist Bild-KI zulässig, sofern sie keine konkrete
Person oder einen konkreten Einsatz vortäuscht.
