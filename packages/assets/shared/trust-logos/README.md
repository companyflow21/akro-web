# shared/trust-logos

Sonstige Vertrauenszeichen, die weder Zertifikat noch Mitgliedschaft noch
Kundenlogo sind — etwa Partnerschaften, Auszeichnungen, Prüfsiegel.

## Bestand

**Leer.** Im Altbestand liegt ein Partnerlogo (`schutzschild_logo_retina`),
zerstört und in seiner Bedeutung ungeklärt.

## Regel

Ein Zeichen kommt nur hierher, wenn belegt ist, wofür es steht und dass AKRO
es führen darf. Zeichen ohne belegbare Grundlage werden nicht verwendet.

Keine KI-Nachbildung.
