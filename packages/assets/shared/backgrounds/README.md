# shared/backgrounds

Neutrale Hintergründe, Texturen und Verlaufsflächen ohne Markenbezug.

## Bedarf

Flächen für Hero- und Sektionshintergründe, die zur Gestaltungsrichtung
passen: technisch, kontrolliert, ohne Motivinhalt.

## Bestand

**Leer.**

## Regel

Hintergründe dürfen keine erkennbaren Objekte, Personen oder Orte zeigen —
sonst gehören sie in eine Bildwelt, nicht hierher. Für rein abstrakte
Flächen ist Bild-KI zulässig.

Vor der Produktion die Designentscheidung abwarten: Format, Zuschnitt und
Farbwelt stehen erst danach fest.
