# shared

Assets, die **alle** Marken gemeinsam nutzen. Alles Markenspezifische gehört
in die jeweilige Bildwelt.

| Ordner | Inhalt |
| --- | --- |
| `certifications/` | Zertifikatszeichen, Normensiegel |
| `memberships/` | Mitgliedschaften und Institutionen |
| `references/` | Kundenlogos und Referenzmaterial |
| `trust-logos/` | sonstige Vertrauenszeichen |
| `company/` | Unternehmensbilder, Standorte, Führung |
| `recruiting/` | Bewerber- und Karrierebilder |
| `backgrounds/` | neutrale Hintergründe und Texturen |

## Grundregel für Fremdmarken

`certifications/`, `memberships/`, `references/` und `trust-logos/` enthalten
**fremde Marken**. Für jede Datei muss dokumentiert sein, woher sie stammt und
wer ihre Veröffentlichung freigegeben hat. Ohne Freigabe wird sie nicht
abgelegt und nicht verwendet.

Keines dieser Zeichen darf mit Bild-KI erzeugt oder nachgebaut werden
(`docs/DECISIONS.md` Punkt 21).
