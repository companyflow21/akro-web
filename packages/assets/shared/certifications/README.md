# shared/certifications

Zertifikatszeichen und Normensiegel.

## Bedarf

ISO 9001 · ISO 14001 · ISO 45001 · SCC · DIN 77200

## Bestand

**Leer.** Im Altbestand liegen intakte SVG-Fassungen aller fünf Zeichen — sie
werden erst übernommen, wenn die Freigabe unten erteilt ist. Die dortigen
PNG-Fassungen sind zerstört und werden nicht übernommen.

## Blockiert

Vor jeder Übernahme müssen kumulativ vorliegen:

1. geprüfte Originalzertifikate
2. bestätigte Gültigkeit und bestätigter Geltungsbereich
3. Freigabe der öffentlichen Darstellung

Solange das offen ist, darf keine Zertifizierung behauptet werden — auch
nicht bildlich. Die Seite `/zertifizierungen` ist deshalb blockiert.

## Darstellungsregel

Neutrale Textsiegel im AKRO-Design. Keine Logos der Zertifizierungsstelle,
keine Zertifikatsnummern. Keine KI-Nachbildung.
