# shared/memberships

Zeichen von Institutionen und Mitgliedschaften.

## Bedarf

IHK · VBG (gesetzliche Unfallversicherung) · gegebenenfalls BDSW, ASW West

## Bestand

**Leer.** Im Altbestand liegen IHK- und VBG-Zeichen, beide zerstört und auf
allen sechs Altseiten eingebunden.

## Blockiert

Für jedes Zeichen ist zu klären, ob eine Mitgliedschaft tatsächlich besteht
und ob das Zeichen geführt werden darf. Ein Institutionszeichen ohne
bestehende Mitgliedschaft ist irreführend.

Keine KI-Nachbildung.
