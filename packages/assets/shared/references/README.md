## Blockiert

Für **keinen** dieser Kunden ist eine Veröffentlichungsfreigabe dokumentiert.
Ohne schriftliche Freigabe je Kunde wird hier nichts abgelegt und nichts
veröffentlicht — weder Logo noch Name noch Projektbeschreibung.

Zu klären ist außerdem, in welcher Detailtiefe Projekte beschrieben werden
dürfen.
