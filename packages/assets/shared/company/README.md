# shared/company

Unternehmensbilder, die alle Marken nutzen: Standorte Saarlouis und Bonn,
Gebäude, Leitung, Verwaltung, Fuhrpark.

## Bestand

**Leer.** Der Bestand des Altbestands ist zerstört.

## Regel

Reale Unternehmensbilder werden **fotografiert, nicht mit KI erzeugt**
(`docs/DECISIONS.md` Punkt 22). Ein KI-Bild darf keinen realen Sachverhalt
vorspiegeln — kein erfundenes Gebäude, kein erfundenes Fahrzeug, keine
erfundene Person als Mitarbeiter.

Abgebildete Personen brauchen eine schriftliche Einverständniserklärung.
