# service

Bildwelt **AKRO Service** (`akro-service.de`). Farbwelt Grün.

Eigenständige Bildwelt (`docs/DECISIONS.md` Punkt 23).

## Bedarf je Leistung

| Leistung | Motividee |
| --- | --- |
| Reinigung | Unterhalts- und Grundreinigung im Objekt |
| Logistik | Warenumschlag, Kommissionierung |
| Transport | Fahrzeug im Einsatz, Verladung |
| Hostessen und Servicepersonal | Empfang und Betreuung bei Veranstaltungen |
| Betriebsunterstützung | allgemeine Unterstützungsleistungen |

Zusätzlich: Hero-Motiv und OG-Bild.

## Bestand

**Leer.**

## Regel zur Bildaussage

Die Motive müssen AKRO als **eigenverantwortlich erbrachte Dienstleistung**
zeigen, nicht als Personalgestellung. Vermeiden: Darstellungen, in denen
AKRO-Kräfte erkennbar in einen fremden Betriebsablauf eingegliedert wirken
oder Weisungen des Auftraggebers entgegennehmen. Das ist keine
Geschmacksfrage, sondern folgt der Abgrenzung Werkvertrag gegen
Arbeitnehmerüberlassung (`CLAUDE.md` §13).
