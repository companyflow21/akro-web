# group

Bildwelt **AKRO Group** (`akro-group.de`). Übergreifende AKRO-Farbwelt.

## Bedarf

Die Portalseite ist bewusst schlank. Gebraucht werden:

- ein ruhiges Leitmotiv für den Einstieg
- je Geschäftsbereich ein Vorschaumotiv für die Weiterleitung
- OG-Bild der Dachmarke

## Bestand

**Leer.**

## Regel

Die Vorschaumotive dürfen die drei Bereiche erkennbar unterscheiden, ohne
Motive aus deren Bildwelten zu doppeln. Sie sind eigenständige Bilder, keine
Zweitverwendung.
