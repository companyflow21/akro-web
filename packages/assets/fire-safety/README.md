# fire-safety

Bildwelt **AKRO Fire & Safety** (`akro-fire-safety.de`). Farbwelt Rot/Orange.

Eigenständige Bildwelt — Motive aus `security/` werden nicht übernommen
(`docs/DECISIONS.md` Punkt 23).

## Bedarf je Leistung

| Leistung | Motividee |
| --- | --- |
| Sicherungsposten | Postenposition an einer Industrieanlage |
| Brandwachen | Brandwache bei Heißarbeiten |
| Gas- und Atmosphärenüberwachung | Messgerät im Einsatz, Behälterzugang |
| Höhensicherung / PSAgA | Sicherung in der Höhe, Anschlagpunkt |
| HSE- und SGU-Dienstleistungen | Unterweisung, Dokumentation vor Ort |

Zusätzlich: Hero-Motiv, OG-Bild, Turnaround- und Stillstandsbegleitung.

## Bestand

**Leer.** Für diese Marke existieren keinerlei Assets.

## Regeln

- Schutzausrüstung muss **fachlich korrekt** dargestellt sein. Falsch
  angelegte PSA oder unrealistische Situationen sind in dieser Branche ein
  Glaubwürdigkeitsschaden und fachlich zu prüfen.
- Keine reale Anlage abbilden ohne Genehmigung des Betreibers.
- Bild-KI zulässig für fachliche Motive, nicht für reale Einsätze.
